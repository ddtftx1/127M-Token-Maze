## BUG-001 · 指南针方向反转

- **发现日期**：2026-10-25
- **状态**：已修
- **优先级**：P0
- **模块**：`js/ui.js` → `updateHud()`
- **现象**：指南针箭头指向与终点实际方位相反。终点在右，箭头指左。
- **复现**：任意难度进入游戏 → 拾取地图 → 走到直走廊，让小地图紫色三角朝向与终点方向明显错开 90° → 观察箭头指向，与小地图终点方向相反。
- **根因分析**：`player.js` 的 `angleToEnd()` 返回 `yawTarget - yaw`，是"相对当前朝向的偏角"。`yaw` 增大实际向左转，所以 UI 上的 `rotate(deg)` 应取反。
- **备注**：改一行。
- **✅ 已修 / 2026-10-25**

## BUG-002 · 指南针形状等边对称，尖端不可辨；旋转轴心偏移

- **发现日期**：2026-10-25
- **状态**：已修
- **优先级**：P0
- **模块**：`css/style.css` `.compass-arrow`、`index.html` `#compass-arrow`
- **现象**：
  1. `▲` 字符是等边三角形，三个角完全对称，从远处看分不清尖端朝哪；
  2. `▲` 字符有基线偏移，`transform-origin` 默认在盒子中心，与视觉重心不一致 → 旋转时三角"甩"到圆环外，轨迹不是同心圆。
- **复现**：进入游戏，旋转视角持续观察指南针。尖端朝向模糊；持续旋转时三角外甩。
- **根因分析**：字符三角 + 字符基线的固有缺陷。
- **备注**：需换成 CSS 绘制的尖长等腰三角，容器旋转、`transform-origin` 居中。
- **✅ 已修 / 2026-10-25**

## BUG-003 · 「最佳路径」不绕开终点、不捡完全场

- **发现日期**：2026-10-25
- **状态**：已修
- **优先级**：P1
- **模块**：`js/main.js` `buildBestPath()` / `autoPathCellLimit()`、`js/pathfinding.js`、`js/shop.js`
- **现象**：
  1. 靠近终点使用「最佳路径」，路径直接冲向终点，忽略周围金币；
  2. 若某金币必须踩过终点才能捡（终点是死胡同口），规划看似绕过去捡，但玩家踩终点即通关，实际捡不到；
  3. 若绕开终点也能捡，规划仍可能选"看似近但穿过终点"的路线，导致该金币漏捡。
- **复现**：简单难度，走到离终点 2–3 格处使用「最佳路径」→ 光带直冲终点，不捡附近金币。
- **根因分析**：
  - 当前语义是"最短路径 + 顺路拾取（maxDetour=4）"，不是全覆盖；
  - `findCollectTargets` 未排除"入口 = 终点"；
  - 绕行与终点判定未隔离。
- **备注**：需改成贪心全覆盖 + 拾取阶段把终点格临时封墙 + 简化时终点格加保护。
- **✅ 已修 / 2026-10-25**

## BUG-004 · 回放跟随视角在困难难度穿墙

- **发现日期**：2026-10-25
- **状态**：已修
- **优先级**：P1
- **模块**：`js/main.js` `updateReplay()`（`replayView === 'follow'` 分支）
- **现象**：通关后看回放，跟随视角在窄巷道中相机穿入墙内，画面变黑。
- **复现**：困难难度完整通关 → 胜利界面点"▶ 回放本局" → 幽灵穿行窄巷道时画面变黑。
- **根因分析**：相机高度固定 2.7m，困难墙高 3.5m → 相机埋在墙里；距离 3.4m 太近、`lookAt` 点 1.15m 太低，幽灵脑袋跑出画面。
- **备注**：
  - 相机高度改 4.5m（高于所有难度墙高）；
  - 距离拉到 5.0~5.5m；
  - `lookAt` 锚点抬到 1.6m；
  - **改完注意**：`maze.js` 天花板材质必须保持 `side: THREE.FrontSide`，否则 4.5m 相机会被天花板挡住。
- **✅ 已修 / 2026-10-25**

## BUG-005 · 彩蛋奖励多次领取后 UI 数字溢出

- **发现日期**：2026-10-25
- **状态**：已修
- **优先级**：P2（极端场景）
- **模块**：`js/ui.js` `updateItemsButton()` / `renderItemPanel()` / `refreshShop()`；`js/shop.js`
- **现象**：反复领取彩蛋（每次 +99999）3 次以上后：
  - HUD "🎒道具 ×179999" 撑开按钮；
  - 商店卡片 "已购 179999 / 99" 横向溢出；
  - 道具面板 "×179999" 同样。
- **复现**：主菜单长按"🏪 商店" → 输入答案领取道具奖励 → 重复 3~4 次 → 进游戏或开商店观察。
- **根因分析**：数字直接拼接，未缩写。
- **备注**：加 `formatCompactNum()` 工具函数（k / w / 亿），套用至上述位置。
- **✅ 已修 / 2026-10-25**

## BUG-006 · 单局超 60 分钟时间格式冗长

- **发现日期**：2026-10-25
- **状态**：已修
- **优先级**：P2（极端场景）
- **模块**：`js/ui.js` `formatTime()`
- **现象**：`formatTime(4000)` 显示 `"66m 40.0s"`，可读性差。
- **复现**：控制台执行 `MG.Game.elapsed = 4000` → 观察 HUD 时间。
- **根因分析**：`formatTime` 只处理秒和分，没有小时段。
- **备注**：加 `s ≥ 3600 → Xh Ym` 分支。
- **✅ 已修 / 2026-10-25**
