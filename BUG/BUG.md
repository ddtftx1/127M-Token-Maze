**新增归档文件时必须满足的 3 条**（提交前自查）：

1. **顶部有 `## 目录`** —— 列全本批每一条 BUG，逐条可点；
2. **每条 BUG 的标题用显式锚点**：`<h2 id="bug-0xx">BUG-0XX · 标题</h2>`
   （**不要**只写 `## BUG-0XX · 标题` 然后靠自动锚点 —— 标题里的标点、`code`、
   全角括号一变，链接就失效）；
3. **非条目章节也给显式 id**（如 `id="files"` / `id="verification"`），目录里的
   「其他章节」用这些 id 链接。

**自查方式**（在仓库根目录执行；输出里每条都应为 `断链： 无 … ✓`）：

```bash
python3 - <<'EOF'
import re, glob
for fn in sorted(glob.glob('BUG/BUG(*.md')):
    lines = open(fn, encoding='utf-8').read().split('\n')
    s = '\n'.join(lines)
    ids = set(re.findall(r'id="([^"]+)"', s))
    links = set(re.findall(r'\]\(#([a-z0-9\-]+)\)', s))
    ent = sum(1 for l in lines if re.match(r'^<h[23] id="bug-\d+">', l))
    first = next((i for i, l in enumerate(lines) if re.match(r'^<h[23] id="bug-\d+">', l)), len(lines))
    toc = len([l for l in lines[:first] if re.search(r'\]\(#bug-\d+\)', l)])
    miss = sorted(links - ids)
    print(fn, '断链：', '无' if not miss else miss, '| 条目', ent, '目录', toc,
          '✓' if (not miss and ent == toc) else '✗')
EOF
```

> 说明：`条目` = 文件里 `<h2 id="bug-0xx">` 的个数；`目录` = **第一个条目标题之前**
> （也就是目录区域）出现的 `#bug-0xx` 链接数 —— 这样只数目录，不会把正文里引用的示例算进来，
> 同时兼容"列表式"与"表格式"两种目录写法。
