## 记录模板

新发现 BUG 时，复制下面的模板追加到"当前状态"上方：

```markdown
## BUG-XXX · 一句话标题

- **发现日期**：YYYY-MM-DD
- **状态**：待修
- **优先级**：P0 / P1 / P2
- **模块**：`js/xxx.js` → `functionName()`
- **现象**：用户能看到/感受到什么。
- **复现**：从哪个界面、做什么操作、观察什么。
- **根因分析**：为什么会这样。
- **备注**：修的时候要特别注意什么。

---
```

**状态取值**：`待修` / `待确认` / `观察中` / `已撤回` / `已修`
**优先级**：P0 立即修 / P1 版本内修 / P2 有空再修
