## 归档规则

1. **一个版本一个文件**，文件名用发布日期：`YYYY.MM.DD.md`
   （与 `BUG/` 归档的 `BUG(YYYY.MM.DD).md` 日期写法保持一致）。
2. 同一天发布多个版本时，在日期后追加序号：`YYYY.MM.DD-2.md`、`YYYY.MM.DD-3.md`。
3. **历史文件不删除、不覆盖、不合并。** 已归档的文件只能追加补充说明
   （例如事后发现漏记一条），并且要在该条目下注明「补充于 YYYY.MM.DD」。
4. 新版本发布时：
   - 新建 `YYYY.MM.DD.md`，格式参照**仓库根目录**的 `_模板.md`（相对本文件是 `../../_模板.md`）；
   - 在下方「版本索引」表格里追加一行；
   - 若该版本修了 Bug，条目里必须写上对应的 BUG 编号（`BUG-0XX`），
     并与 `BUG/` 目录下的归档文件互相引用。
5. 本目录**只记已经做完的内容**。打算做但没做的写在 `../README.md` 的「更新计划」里，
   不要提前塞进日志。
