# 2026-10-30 版本说明（归档）

> 本目录是**历史版本归档**。日志正文见 `2026.10.30.md`（与归档前的根 `CHANGELOG.md`
> 字节级一致，10,005 字节）。**当前最新版本在仓库根目录的 `../../CHANGELOG.md`。**

## 这一版做了什么

- **跨平台兼容**：39 处 Emoji 换成 16 个内联 SVG（新增 `js/icons.js`），
  老内核（Win7 + Chrome 49）补 `legacy-*` 降级，修掉退出全屏后误入手机横屏与右侧白条；
- **交互修复**：回放模式点击画面不再误锁鼠标、按 P 不再直接退出回放；
  通关成就提示在快速离开本局时不再丢失；
- **地图道具改版**：拾取地图卷轴从"立即解锁小地图"改为"进背包（`mapUnlock` +1），
  由玩家在道具面板主动使用后才解锁"；
- **地图卷轴视觉**：卷轴杆与地图板改为整体绕 Y 轴同步自转（BUG-021）。
