## 版本主题

新增「每日签到」系统，并修复 BUG-022（先解锁小地图后地图卷轴捡不起来）。

**范围**：新增 `js/checkin.js`；`js/shop.js`（新增「签到护符」商品与钱包字段）、`js/ui.js`、
`js/main.js`、`index.html`、`css/style.css`、`js/icons.js`（新增 2 个图标）。
玩家可感知的变化：主菜单多一个「每日签到」按钮与签到面板；商店多一件商品。

**兼容性**：**没有改动任何既有存档字段的语义**。`localStorage` key 全部保持原样
（`maze3d.wallet.v1` 等 7 个），新增第 8 个 key `maze3d.checkin.v1` 只存签到数据。
钱包**新增一个字段** `streakShield`（向后兼容：老存档读进来补 0，不丢数据、不崩），
已在 `normalizeWallet` 白名单登记，刷新后不会丢。回放压缩帧格式、排行榜分区、
`MG.*` 既有方法签名**全部未变**，无需迁移。

## 新增

### 每日签到（入口：主菜单 → 「📅 每日签到」）

- **入口位置**：竖屏在「商店」与「成就」之间；横屏（含电脑）在左列难度卡片组下方。
  未领取时右上角带红点角标，领取后按钮变为「✓ 今日已签到」并置灰（仍可点开查看进度）。
- **自动弹出**：每次进入游戏（页面加载）后 700ms 自动打开一次签到面板；本会话只弹一次，
  若玩家已经点了「开始游戏」则不打扰。
- **奖励规则**：
  | 情形 | 奖励 | 概率 |
  |---|---|---|
  | 历史首签（账号第一次签） | **1 金币** | 一次性 |
  | 常规日 | **5~10 金币**（整数均匀随机） | — |
  | 连签第 7 / 14 / 21… 天 | 5~10 金币 **+ 保底道具 ×1**（小地图解锁 → 最快路径 → 最佳路径 轮换） | 每 7 天必出 |
  | 财宝箱 | 额外随机道具 ×1 | **8%** |
  | 签到大吉 | 当日金币 **×3**（15~30） | **1%** |
- **7 格进度面板**：已签=对勾、今天=闹钟（呼吸高亮）、未来=锁（不可点击，也不能提前签到）；
  第 7 格右下角挂保底道具角标。底部有「距下次签到 X 小时 Y 分 Z 秒」倒计时，
  仅在面板打开时每秒刷新，关闭即停。
- **奖励预告即实发**：面板打开时摇一次骰子并缓存，面板显示的数字就是点「领取」时真正到账的数字。
- **断签规则**：漏签后连签清零回第 1 天（断签后第 1 天按常规 5~10 发）。

### 签到护符（入口：主菜单 → 商店，第 5 件商品）

- 价格 **40 金币**（计数类道具里最贵），**自动生效、无需手动使用**，所以不出现在道具面板，
  数量显示在签到面板头部。
- 漏签 **1~5 天**时自动消耗 1 个，连签保留并 +1（漏掉的日子不补发奖励）；
  漏签 **≥6 天**视为彻底中断，护符不生效也不消耗。
- 与拾取 / 商店购买的道具共用同一份钱包计数（`maze3d.wallet.v1`）。

### 图标

- 新增 `shield`（🛡 盾牌）与 `alarm`（⏰ 闹钟）两个内联图标，图标总数 16 → 18。
  闹钟带 3 个渐变 id，靠既有的多实例 id 唯一后缀机制隔离，同页多处出现不会串色。

## 调整

- **拾取分支的守卫语义**（BUG-022）：`if (!Game.mapFound && tryCollectMap(...))` →
  `if (tryCollectMap(...))`，分支内按 `Game.mapFound` 分流。原因：`&&` 短路使
  "先解锁后拾取"这条路径完全不可达。
- **已解锁时的拾取 toast 文案**：`已获得地图道具，可在道具面板中使用` →
  `已获得地图道具（库存 +1）`。原因：本局小地图已经解锁，再说"可在道具面板中使用"是误导，
  该道具实际是留给下一局的。
- **「最佳路径」目标收集**：去掉 `&& !Game.mapFound`。原因：本局已解锁时卷轴依然可拾取，
  若继续过滤，自动寻路就不会绕路去捡它，与本局实际行为不一致。
- **道具面板过滤规则**：跳过 `passive: true` 的道具（当前只有签到护符）。
  原因：该面板每行都带「使用」按钮，而护符是自动生效的，放进来只会让人点了没反应。
- **钱包结构**：新增 `streakShield` 字段（`DEFAULT_WALLET` + `normalizeWallet` 白名单各一行）。

## 验证

- **静态检查**：13 个 JS `node --check` 全部通过；`checkin.js` / `ui.js` / `shop.js` / `main.js`
  剥注释后做 ES5 约束扫描（`let` / `const` / 箭头函数 / 模板字符串 / `class`）0 命中；
  `index.html` 的 16 个签到相关 id 齐全，脚本顺序 `ui.js → checkin.js → main.js` 正确。
- **签到逻辑（129 项断言全绿）**：
  - 日期口径：`dayKey()` 与 `MG.Maze.dailySeed()` 逐日一致（含闰日 2024-02-29、跨月、跨年），
    23:59 → 00:00 跨天正确；
  - 首签：200 次不同随机源下金币恒为 1、无道具；
  - 常规日：1200 次抽样全部落在 5~10，六个值齐全且分布最大偏差 < 3%；
  - 保底道具：第 7 天必出小地图解锁、第 14 天必出最快路径（轮换正确），第 6 天不出；
  - 稀有：宝箱 8%±2%、大吉 1%±1%（10000 次统计），大吉金币恒为 15~30 且是 3 的倍数；
  - 护符：漏 1 天清零（无护符）/ 漏 5 天消耗 1 个保住连签（5→6）/ 漏 6 天不生效也不扣 /
    连续签到时从不消耗；
  - 交互：PC 上按 ESC / P 可关闭签到面板（与道具面板、设置面板同一手感）；
  - 幂等与安全：同日二次、三次领取均失败且钱包与存档零变化；时间倒流拒绝发放、`anomaly` +1、
    恢复后可继续签；
  - 健壮性：10 种损坏存档（`"{"` / `null` / 数组 / `streak:"abc"` / 非法日期 / 空串…）全部自愈不抛错；
    `localStorage` 抛异常时内存降级仍可签且不重复；
  - 入账一致性：金币精确 +N、道具进同一份钱包、与商店购买共用计数、新字段落盘含 `streakShield`；

- **BUG-022 回归**：38 项断言全绿（分支语义 / 迷宫层 / 目标收集 / 迷宫 36/36 / 静态）。
- **真机 / 浏览器人工验收（仍待确认）**：
