## 与后续版本的关系

⚠️ **口径订正（请在阅读本版时注意）**

本版正文里多处写「老内核（Chrome 49 / Win7）」。这个口径是**误记**：
Win7 上最后能装的 Chrome 是 **109**，不是 49（用户 2026-11-07 当面纠正）。

- 按「历史只增不改」，本目录正文保持原样，不做改写；
- 由于基线实际是 109，本版补的那些**能力补偿**（`legacy-env` / `legacy-inset` /
  `legacy-gap` / `legacy-dvh`）在 109 上一个都不会触发 —— 它们本身没有害处，
  但**不能再拿来当"老内核模拟"用**。这正是 2026-11-07 版 BUG-032 的成因：
  那套"模拟"改成三档真正会降低 UI 观感的 `sim-legacy-*`。
- 结论：本版的技术改动**不算错**（向下兼容无副作用），但**紧急度被高估**了。
  详见 `../../BUG/BUG(2026.11.07).md` 的「口径订正」一节。
