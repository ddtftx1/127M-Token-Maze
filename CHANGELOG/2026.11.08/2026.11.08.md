## Bug 修复

> 根因分析、修复细节与验证过程见 `BUG/BUG(2026.11.08).md`。

- **BUG-045** · 开发者面板「删除此项 / 清空全部 / 导入存档」后钱包的内存缓存不失效，
  下一次加币或购买会把刚删掉的钱包整份写回，已改为让钱包缓存同步作废。
- **BUG-046** · 非法用时（`NaN`）会被写成"0 秒最佳记录"并永久霸榜，
  使该难度的最佳记录从此不再更新，已改为拒绝非法入参并让存量 0 秒记录自愈。
- **BUG-047** · 画质切换时若渲染器重建失败，再切回旧档会被"档位没变"跳过，
  导致 MazeView 永久停在新档（墙檐 / 粒子 / 阴影与设置不一致），已改为档位同步不受重建结果影响。
- **BUG-048** · 进入全屏成功后 900ms 内按 ESC 退出，会误报一条「进入全屏失败」
  （退出方向同理），已改为"目标状态达成过即算成功"，同时仍如实报出真正的失败。
- **BUG-049** · 商店购买 / 消耗道具在 `localStorage` 写盘失败时被静默吞掉、仍提示「购买成功」，
  已改为**回滚内存改动并如实提示**，并把"余额不足"与"存档不可写"区分开。
- **BUG-050** · 系统时间被调到未来后调回（或导入未来日期存档）会把签到**永久锁死**，
  连签与护符全部失效；已改为**连续 3 天检测到时钟倒退即按当天重置基准日自愈**，
  并在提示里说清为什么连签回到第 1 天。
- **BUG-051** · 排行榜存档里"用时 ≤ 0 / 步数为负"的脏数据会永久霸占榜首，
  已按与写入侧一致的口径在读盘时过滤。
- **BUG-052** · 成就计数器为字符串（`"5"`）时会被 `+1` 拼成 `"51"`，已补数值类型守卫。
- **BUG-053** · 切画质 / 上下文丢失救援会整张替换 `<canvas>`，而鼠标监听仍留在旧节点上，
  已改为由输入层的 `setCanvas()` 解绑重绑（带新旧版本兼容兜底）。
- **BUG-054** · WebGL 上下文恢复期间，`F`（开道具面板）与 `R`（重开一局）仍会改状态机，
  已加恢复期早退。
- **BUG-055** · 站定后启动自动寻路全程没有头部晃动（与代码里推进晃动相位的意图不符），
  已按与手动行走同一口径补齐阻尼恢复。
- **BUG-056** · 开发者面板「快速跳转 → 设置」在暂停局里点「返回」会落到主菜单、
  把暂停局盖在下面，已按来源正确返回暂停菜单。
- **BUG-058** · 钱包余额被手改 / 导入成 `1e308` 级数值时，加币会溢出成 `Infinity`、
  落盘成 `null`、下次启动静默清零；已加数值上限（`Number.MAX_SAFE_INTEGER`）并在四个入口统一钳制。
- **BUG-059** · 彩蛋验证弹窗的"合成点击"防护只覆盖 `detail === 0`（与注释"一律忽略"不符）；
  用户 2026-11-09 **真机复测未复现**，条目按"已核实正常"关闭，未改代码。
- **BUG-060** · 时钟倒退被拦的第 1~2 天，签到入口角标仍显示「今日已签到」而实际签不上；
  已改为如实的「系统时间异常」并把图标换成锁（可领取 / 已领取 / 自愈当天三种状态未动）。
- **BUG-057** · 四处注释 / 文档口径订正：`js/main.js` 的「Chrome 49」横幅改为 **109**、
  `js/input.js` 的 `hud` 参数注释改准、`css/style.css` 主题变量表头注释改准
  （并标注三个预留端口不可删）、`README.md` 补上漏掉的 `js/dev.js` 一行、`.gitignore` 的 svg 数量 18 → 19。

## 新增

> 均为**仓库外**的开发用产物（按 `.gitignore` 与既有约定不入库），玩家侧无新入口。

- `svg/`（**工作区根目录，仓库外**）：把 `js/icons.js` 里内联的 **19 个 SVG 图标**抠成独立文件
  （中文名沿用源码注释里的原始文件名，如 `🏆 奖杯.svg`、`🗺 地图.svg`），
  逐个校验为合法且自包含的 SVG，并与内联字符串**逐字节一致**。运行时仍用内联版（`file://` 无 CORS 问题），
  这些文件只作查看 / 编辑 / 重新导出的素材。
- `extract-icons-to-svg.js`（工作区根目录，**仓库外**）：上面那步的可重复执行脚本，
  改完图标后重新导出用。
- `harness/`（工作区根目录，**仓库外**）：jsdom 无头冒烟测试基建。一条命令跑完 9 个场景
  （加载挂载、开局、移动与计时、暂停与道具面板不变量、通关与四类存档落盘、资源释放与幽灵重开、

  **边界**：无真实 WebGL，渲染正确性 / 画面布局 / 真机手感不在覆盖范围内。
- `audit/`（工作区根目录，**仓库外**）：本批 4 份审查报告（引擎 / 玩法 / 界面 / 数据），
  含逐条 `文件:行号`、根因、修法与复算数字。
- `js/checkin.js` 的签到存档新增字段 `anomalyFrom`（时钟异常锚点，用于 BUG-050 的自愈判定；
  老档缺失时按"第 1 天"处理，无需迁移）。
- `MG.Shop` 新增两个导出：`invalidateCache()`（作废钱包内存缓存）、
  `takeSaveError()`（取走最近一次写盘失败的操作名，供界面如实提示）；
  另导出上限常量 `MAX_WALLET_VALUE`。

## 调整

- **商店失败提示分层**：`金币不足` / `已达购买上限` 之外，新增
  「购买失败：本地存档无法写入（隐私模式或空间已满）」；道具使用失败时同理区分
  「道具不足」与「本地存档无法写入，道具未使用」。**成功路径文案一律未改。**
- **签到时钟异常提示**：第 1~2 天被拦时补"连续 3 天仍未恢复将自动重置签到基准日"；
  自愈当天在面板与领取 toast 里说明"已按今天重新开始累计连签"。
- **自动寻路手感**：站定后启动寻路，相机恢复与手动行走一致的步伐晃动（约 0.25s 起振到满幅 0.045m）；
  手动行走手感完全不变。
- **钱包数值上限**：金币与道具数量统一钳制到 `Number.MAX_SAFE_INTEGER`（约 900 万亿），
  超出收敛到上限而不是溢出成 `Infinity`；正常玩法与本局奖励完全不受影响。
- **签到角标文案**：时钟异常第 1~2 天显示「系统时间异常」（图标由对勾换成锁），
  不再声称"今日已签到"。
- **`--theme-wall` / `--theme-floor` / `--theme-fog` 保留不动**：复查确认这三个 CSS 变量当前
  没有任何规则引用（3D 颜色来自 `js/maze.js` 的 `THEMES`），但它们是**有意保留的预留端口**，
  按用户要求不删；仅在表头注释里写明这一点。
- **`js/player.js` 零功能改动**：碰撞、自动寻路推进、限程停止、坐标换算全部复算通过，未做任何"顺手重构"。
