## 这一版做了什么

- **用户反馈驱动的修复**（BUG-061 ~ BUG-063）：
  ① 开发者面板里 `MG.Audio.portal()` 不发声却提示"已播放"（唯一"300 Hz 以上零能量"的低频纯正弦，
  手机小喇叭放不出来 + 面板提示无条件为真；已加泛音并按上下文状态如实反馈）；
  ② **P0** 电脑/笔记本/平板的小地图被 `min(34vw, 168px)` 上限钉死、任何难度都看不清
  （改为随视口比例自适应，并在设置面板新增「小地图大小」三档与徽标提示）；
  ③ BUG 归档文件缺目录、查历史缺陷只能 `Ctrl+F`（7 个归档文件全部补齐 `## 目录` +
  显式锚点 `<h2 id="bug-0xx">`，并把这条要求写进模板与 `BUG/BUG.md`）。
- 新增仓库外的音效体检工具（`harness/audio-render.js`：把 `audio.js` 真跑一遍离线渲染成 WAV
  并输出频段能量表），以及 BUG-061 的修复前后对比样本。
