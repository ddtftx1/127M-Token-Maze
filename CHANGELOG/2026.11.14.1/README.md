## 这一版做了什么

- **终点位置规则重做（BUG-067，P1）**：终点原先**永远固定在右下角**（三档各 200 局，唯一终点数 = 1）——
  根因是 `pickEndpoints()` 用**曼哈顿距离**取最远格，而曼哈顿距离在角落取到唯一最大值，
  `farCell` 这个难度开关实际是死逻辑。已按用户口径改为
  **随机于"从起点出发的路径步数 ≥ 80% 本局最远"的通路格**（BFS 真实路径距离 +
  种子派生的独立随机流 + 非空象限分层）。
- **同族第二处**：ESC / P 优先级链缺三个覆盖层的分支 → 暂停局按 ESC 会把对局恢复起来而面板不关，
  之后返回还会算成落主菜单、对局在背后跑到终点凭空写成绩。已与鼠标返回走同一条路径。
- **同族第三处（用户口径 A）**：已通关后从胜利界面进覆盖层的返回落点 → 回胜利界面。
- **回放 / 幽灵布局版本**：`LAYOUT_VERSION` 2 → 3，旧布局记录读到即作废并删除。
- **`prune()` 清理顺序修正**（独立验证者发现）。

## 与后续版本的关系

  原中等升为简单、原困难升为中等、新增 **121×121（60×60 单元格）**巨型困难；
