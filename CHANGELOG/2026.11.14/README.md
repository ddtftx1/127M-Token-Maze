## 这一版做了什么

- **导航一致性收口（BUG-064 ~ BUG-065）**：
  - BUG-064：对局暂停中经开发者面板「快速跳转」进 商店/排行榜/成就/签到，点「返回」会落到主菜单，
    把主菜单盖在一局还没释放的僵尸对局上（BUG-056 的同族遗留）→ 返回落点在 UI 层按 `Game.state`
    统一判定，ESC / P 与鼠标点「返回」走同一条路径；
  - BUG-065：同一族第三处（已通关后从胜利界面进覆盖层）→ 按用户口径 **A 回胜利界面**。
- **BUG-066 性能优化**：修掉"游戏内流畅、主界面与 UI 面板滑动卡顿"——
  菜单/暂停/胜利态下那张没人看得见的 3D 画面不再逐帧渲染（菜单 60 帧渲染 60 → 0）、
  全屏毛玻璃移出滚动容器、签到呼吸动画改合成器属性、11 处滚动容器加滚动链隔离。
- 归档了上一版日志（`CHANGELOG/2026.11.09/`），并把根日志重新从 `_模板.md` 起写。
