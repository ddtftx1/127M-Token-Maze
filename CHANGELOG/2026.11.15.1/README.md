## 这一版做了什么

同日补版（2026-11-15 的第二个版本）：

- **地图「点击最大化」M2/M3**：`#map-full` 在 `#app` 下与 `#hud` 平级、`z-index:10`；
  非模态（不改 `state`、不暂停）、留白 `pointer-events:none` 穿透（点留白不关、仍能滑视角）、
  专用关闭按钮、`M` 保持"小地图开/关"语义 + 新增 `V` 键；入口只允许 `playing` 态打开。
- **BUG-069**：设置里调「小地图大小」时徽标数值不实时刷新 → `readMinimapSizePx()` 四级回退
  （量容器 → 读 CSS 变量 `--minimap-size` → 探针让浏览器求值 clamp → 只显示档位），
  不在 JS 里复制 clamp 公式。归档见 `../../BUG/BUG(2026.11.15).md`。
- **大迷宫性能三件套（第一批）**：终点距离场缓存（每跨格取距离 2.3ms→0.2ms、值逐格一致）、
  "最快路径"改用距离场梯度下降（与 A\* 等长）、回放采样间隔按迷宫大小自适应
  （巨型迷宫 200ms，30 分钟不再被截断）、小地图静态层失效条件收窄（跨格 60 次：59 次重绘 → 0 次）。
