## 这一版做了什么

2026-11-15 的第三个版本（同日第二次补版），把"大迷宫"的性能与可读性再推一档：

- **最大化地图新增缩放 / 平移**：连续捏合 **1×~8×**（锚点 = 两指中点）+ 拖动平移；
  三条写入口内部统一钳制（不许把地图拖出屏幕、倍数钳在 [1,8]）；纯绘制变换，
  HUD 小地图视图恒为 1/0/0，只放大已探索区域。
- **关闭按钮始终可点**：最大化地图开着时不再重新锁定指针（锁定后光标隐藏、点击落不到 DOM）。
- **性能三件套**：**墙体合并**（默认开，相邻墙格按区块合并为大长方体，按面尺寸重算 UV 保证砖纹密度不变）、
  **「性能模式」**（默认关，一键级联降级并可逆）、**「视距裁剪」**（默认关，按区块隐藏远处的墙）。
