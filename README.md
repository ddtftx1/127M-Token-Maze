# 🎮 3D迷宫探险 (127M-Token-Maze)

> **“本项目的所有代码由 AI 编写，所有提示词也由 AI 编写。人类（我）只负责提出异想天开的需求、测试、截图报错、以及按下回车键。”**

这是一个完全在浏览器端运行的 Web 3D 第一人称迷宫游戏。它没有使用任何外部 3D 模型和图片贴图，所有场景、墙体纹理、音效均由代码动态生成。

### 🌐 在线试玩
👉 **[点击这里，立即体验 3D 迷宫](http://3dgames.mydesktop2026.dpdns.org)**

---

## 💰 开发账单 & 技术栈
*   **开发成本**：¥ 15.71 人民币 / 191,742,139 Tokens
*   **核心引擎**：Three.js (WebGL) / 原生 JavaScript
*   **音效系统**：WebAudio 程序化合成（无外部音频文件）
*   **纹理渲染**：Canvas API 动态生成
*   **AI 合伙人**：DeepSeek (代码生成) / AI 提示词助手（也是Deepseek) (需求拆解)

---

## 🕹️ 游戏特色 (Features)
*   🎯 **第一人称控制**：移动端支持虚拟摇杆，PC 端支持 WASD 移动与 Pointer Lock 鼠标视角锁定。
*   🧭 **智能自动寻路**：内置 A* 算法（带二叉最小堆优化），支持“最佳路径”（顺路拾取金币）与“最快路径”（直奔终点）。
*   👻 **幽灵对战系统**：系统会自动记录你的通关录像。下次挑战相同种子时，可以召唤过去的“幽灵”和自己同台竞技。
*   🗺️ **探索与解锁**：初始小地图是锁定的，必须在迷宫中寻找到“地图卷轴”才能解锁，大幅增加探索感。
*   🏪 **商店与道具**：通关和捡金币可以购买道具，甚至买断金币收益加成。
*   🤫 **隐藏彩蛋**：主菜单长按“🏪 商店”按钮，输入特定的神秘代码，会有惊喜。

## 🔄 赛博套娃开发架构
本项目采用了一种极其奇特的“多 Agent 协同”开发模式：

```text
① 我：提出需求 / 目标
        ↓
② AI1：生成提示词 vN
        ↓
③ 我：人工转交提示词 vN 给 AI2
        ↓
④ AI2：写代码，并启动本地服务器
        ↓
⑤ 本地服务器：运行 3D 迷宫游戏
        ↓
⑥ AI2：获取运行/测试结果
        ↓
⑦ AI2：把“代码文件 + 测试结果”发给我
        ↓
⑧ 我：把代码和测试结果回灌给 AI1
        ↓
⑨ AI1：审查代码，输出 Bug 清单 + 修复建议
        ↓
⑩ 我：收到 Bug 建议，要求 AI1 生成下一轮提示词
        ↓
⑪ AI1：生成提示词 vN+1
        ↓
⑫ 我：人工转交 vN+1 给 AI2
        ↓
    回到第④步，循环

AI1 不直连 AI2；
所有跨 AI 的传递都经过“我”；
本地服务器只和 AI2 交互；
测试结果先到“我”，再由“我”回灌给 AI1。
```
