# 🎮 3D迷宫探险 (127M-Token-Maze)

> **“本项目的所有代码由 AI 编写，所有提示词也由 AI 编写。人类（我）只负责提出异想天开的需求、测试、截图报错、以及按下回车键。”**

这是一个完全在浏览器端运行的 Web 3D 第一人称迷宫游戏。它没有使用任何外部 3D 模型和图片贴图，所有场景、墙体纹理、音效均由代码动态生成。

### 🌐 在线试玩
👉 **[点击这里，立即体验 3D 迷宫](http://3dgames.mydesktop2026.dpdns.org)**

---

## 💰 开发账单 & 技术栈
*   **开发成本**：¥ 7.26 人民币 / 127,804,139 Tokens
*   **核心引擎**：Three.js (WebGL) / 原生 JavaScript
*   **音效系统**：WebAudio 程序化合成（无外部音频文件）
*   **纹理渲染**：Canvas API 动态生成
*   **AI 合伙人**：DeepSeek (代码生成) / AI 提示词助手 (需求拆解)

---

## 🕹️ 游戏特色 (Features)
*   🎯 **第一人称控制**：移动端支持虚拟摇杆，PC 端支持 WASD 移动与 Pointer Lock 鼠标视角锁定。
*   🧭 **智能自动寻路**：内置 A* 算法（带二叉最小堆优化），支持“最佳路径”（顺路拾取金币）与“最快路径”（直奔终点）。
*   👻 **幽灵对战系统**：系统会自动记录你的通关录像。下次挑战相同种子时，可以召唤过去的“幽灵”和自己同台竞技。
*   🗺️ **探索与解锁**：初始小地图是锁定的，必须在迷宫中寻找到“地图卷轴”才能解锁，大幅增加探索感。
*   🏪 **商店与道具**：通关和捡金币可以购买道具，甚至买断金币收益加成。
*   🤫 **隐藏彩蛋**：主菜单长按“🏪 商店”按钮，输入特定的神秘代码，会有惊喜。

## 2026-10-25 · 适配、修复与体验优化合集

> 纯前端改动，无新增依赖；localStorage key 与存档格式保持兼容。

### 布局适配
- 手机横屏（高度 ≤ 640px）重新排版：主菜单左右两列、设置分组两列、胜利统计双列、
  暂停菜单 2×2，HUD 四角控件缩尺寸不移位；竖屏与桌面端布局零改动。

### Bug 修复
- 暂停 → 设置 → 返回后 HUD 消失，继续游戏也无法恢复。
- 桌面端鼠标拖出窗口再松开后视角持续自转：改为标准 Pointer Lock（点击画面锁定、ESC 退出，
  支持禁用鼠标加速，触屏笔记本也能用）。
- 幽灵弹窗可被重复打开导致旧流程挂起、弹窗叠加，且 15 秒后会自动替玩家选择：现在必须主动选择。
- 切换主题后墙体 / 地板 / 天花板 / 背景 / 平行光颜色不跟随。
- 高 DPR 手机上小地图发虚（按设备像素比放大画布）。
- 打开道具面板后 HUD 上的暂停按钮点了没反应。
- 色盲友好模式形同虚设：新增蓝-橙 UI 配色、小地图「颜色 + 形状」双编码、
  3D 场景金币/卷轴/起点/终点中文标识，并支持局内实时开关。
- 静止时相机仍有持续细微浮动。
- 自动寻路被卡住时一顿一顿地抽搐；「最佳路径」顺路绕行过远。
- 快捷键盘会误伤输入框（TEXTAREA / 可编辑区域）。
- 首次进入游戏点击音效无声（音频解锁兜底）。
- 同样快但步数更少时无法刷新最佳记录（浮点严格相等比较）。
- 回放可能撑爆 localStorage（24 局 → 8 局、单局 12000 → 9000 帧，写入失败自动清理重试并提示）。
- 自动寻路光带几何体/材质未释放造成的显存泄漏；fatal 错误后渲染循环空转。
- 小迷宫下 farCell 终点永远无候选、幽灵冲线姿态不精确。

### 新增与调整
- 设置新增「小地图显示全部金币」：未探索金币以半透明轮廓显示（默认关闭）。
- 主菜单「成就」由折叠面板改为独立页面，横屏下不再撑高菜单。
- 彩蛋奖励 99 → 99,999（toast 使用千分位显示）。
- 手动调整画质后不再被「自动性能适配」静默降回。

### 性能
- HUD 到终点距离不再每 100ms 做一次全图 BFS（同格复用缓存）。
